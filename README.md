# BRAINROT CASES — Telegram Mini App

В архив собраны обновления в одном проекте:
- тёмный неоновый интерфейс в духе Upgrader/Caser;
- главная страница и нижняя навигация;
- кейсы с заранее указанными наградами;
- раздел апгрейда персонажей;
- коллекция и профиль;
- раздел пополнения с каталогом и ценами из списка;
- 16 изображений персонажей из предоставленного скриншота.

## Установка
Загрузите содержимое папки `brainrot_cases_updated` в текущий проект Vercel. Главный файл — `index.html`, папку `assets` нужно загрузить вместе с ним. Если проект уже привязан к Telegram-боту, оставьте прежний URL Mini App.

## Важно
Это демонстрационная версия: баланс, коллекция и заявки хранятся в localStorage браузера и не синхронизируются между устройствами. Заявки не поступают администратору автоматически. Для реального запуска понадобится серверная база данных и проверка операций. Игровые монеты не имеют денежной стоимости; кейсы показывают гарантированную награду, апгрейд не использует случайные ставки. Никогда не вводите пароль, коды входа или cookie Roblox.
